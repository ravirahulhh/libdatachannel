# ICE+QUIC 速度测试工具

基于 ice_quic_transport 的高性能速度测试工具，用于测试两台服务器之间的传输速度。

## 特性

- 🚀 **高性能传输**: 基于 ICE+QUIC 协议栈
- 📊 **实时速度监控**: 每秒更新发送/接收速度
- 📈 **详细统计**: 显示平均速度、总数据量、传输时间
- 🔧 **灵活配置**: 可配置传输数据量（GB为单位）
- 🌐 **NAT 穿透**: 支持跨 NAT 和防火墙传输
- 🇨🇳 **中文界面**: 友好的中文提示信息

## 快速开始

```bash
# 1. 编译
cd ice_quic_transport
./build_speed_test.sh

# 2. 生成证书
cd build
openssl req -x509 -newkey rsa:2048 -keyout server.key -out server.crt \
    -days 365 -nodes -subj "/CN=localhost"

# 3. 服务端（服务器 A）
./speed_test_server server.crt server.key

# 4. 客户端（服务器 B）- 发送 5 GB 数据
./speed_test_client 5
```

## 常见问题

### Q: 连接超时怎么办？
A: 检查以下几点：
1. ICE 候选格式是否正确（不要包含 `a=` 前缀）
2. 防火墙是否允许 UDP 流量
3. 两台服务器网络是否可达

详见 [故障排查指南](TROUBLESHOOTING.md#1-连接超时)

### Q: 如何提高传输速度？
A: 可以尝试：
1. 使用更好的网络环境（千兆/万兆网卡）
2. 调整数据块大小（修改代码中的 `chunkSize`）
3. 增加 UDP 缓冲区大小（系统参数）

详见 [故障排查指南](TROUBLESHOOTING.md#性能优化建议)

### Q: 支持哪些操作系统？
A: 
- ✓ Linux (Ubuntu, Debian, CentOS, RHEL)
- ✓ macOS
- ? Windows (未测试)

## 技术架构

```
┌─────────────────────────────────────────────────────────────┐
│                     应用层 (Application)                      │
│              speed_test_client / speed_test_server           │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│                  传输层 (ice_quic_transport)                 │
│  ┌──────────────────────┐      ┌──────────────────────┐    │
│  │   QUIC (lsquic)      │      │   ICE (libnice)      │    │
│  │  - 流管理            │      │  - NAT 穿透          │    │
│  │  - 拥塞控制          │      │  - 候选收集          │    │
│  │  - 可靠传输          │      │  - 连接建立          │    │
│  └──────────────────────┘      └──────────────────────┘    │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│                      网络层 (Network)                         │
│                      UDP over IP                             │
└─────────────────────────────────────────────────────────────┘
```

## 性能参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 数据块大小 | 64 KB | 每次发送的数据块大小 |
| 统计更新频率 | 1 秒 | 速度统计更新间隔 |
| 连接超时 | 60 秒 | ICE 连接建立超时 |
| 空闲超时 | 5 分钟 | QUIC 连接空闲超时 |
| 最大流数量 | 100 | QUIC 最大并发流数 |
