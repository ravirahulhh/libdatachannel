## 技术细节

### 传输协议
- **ICE**: 使用 libnice 实现 NAT 穿透
- **QUIC**: 使用 lsquic (基于 BoringSSL)
- **传输层**: UDP

### 性能参数
- **数据块大小**: 64 KB（可调整）
- **统计更新频率**: 1 秒
- **默认连接超时**: 60 秒
- **默认空闲超时**: 5 分钟
- **最大流数量**: 100

### 速度计算
- **发送速度**: 基于实际发送的字节数
- **ACK 速度**: 基于 QUIC 层确认的字节数
- **接收速度**: 基于实际接收的字节数
- **平均速度**: 总数据量 / 总时间

## 使用示例

### 基本用法
```bash
# 编译
cd ice_quic_transport
./build_speed_test.sh

# 生成证书
cd build
openssl req -x509 -newkey rsa:2048 -keyout server.key -out server.crt \
    -days 365 -nodes -subj "/CN=localhost"

# 服务端
./speed_test_server server.crt server.key

# 客户端（发送 5 GB）
./speed_test_client 5
```

### 测试连接
```bash
cd build
./test_connection.sh
```

1. **手动交换 ICE 信息**: 需要手动复制粘贴 ICE 描述信息
2. **单流传输**: 当前版本使用单个 QUIC 流
3. **自签名证书**: 需要手动生成 TLS 证书
